# Канал обновлений и отчёты о проблемах 0.7.1

📣 **Канал «Обновления БРЕД».** Теперь он есть у всех, первым в списке каналов. Как только выходит новая версия, сюда приходит её описание — вот как это, — а установить её можно прямо из поста.

🐞 **Сообщить о проблеме.** Настройки → «Сообщить о проблеме» (или команда `/баг`): выберите, что не так, опишите и прикрепите фото или видео. Отчёт сразу уходит разработчику, а вы получаете его номер.

🧾 **Журнал работы — одной галочкой.** К отчёту можно приложить журнал последних минут: без него сетевые проблемы почти не разобрать. Переписка и ключи туда не попадают никогда.

🔢 **Ваш номер.** У каждого теперь есть короткий номер — его видно в форме отчёта, по нему ищутся все ваши обращения.
